    1) AI 커넥트 연결

    ○ 1단계. 글 쓸 AI 고르고 로그인 [매뉴얼 보기]

    ⚠️ 이 단계는 프로그램을 만들거나 고치는 것과 전혀 상관없습니다. 이 프로그램이 글을 쓸 때 AI 명령 도구를 실행하는데, "누구의 계정으로 실행할지" 딱 한 번 등록해두는 로그인 절차일 뿐입니다. 코드를 건드리거나 재배포할 필요가 전혀 없어요.

    어느 AI 로 쓰시겠습니까

      ✅ 이 AI 는 검은 창(Cloud Shell)이 필요 없습니다. 키 한 줄을 아래 칸에 넣고 [저장]만 누르시면 끝입니다.

      키 받으러 가기 ↗

      어느 모델로 쓸까요 — 글의 품질이 여기서 갈립니다.

      이 매뉴얼은 Claude 나 Codex 를 고르셨을 때만 필요합니다. Gemini 를 고르셨다면 통째로 건너뛰세요 — 검은 창 없이 키 한 줄이면 끝입니다. (아래 예시 명령은 Claude 기준입니다. Codex 면 claude 를 codex 로, .claude 를 .codex 로 바꿔 읽으시면 됩니다. 위쪽 카드에는 고르신 AI 에 맞게 이미 채워진 명령이 나옵니다 — 그걸 쓰시는 편이 안전합니다.)

      🔵 준비 단계

      ☐ console.cloud.google.com 접속 (구글 로그인 상태여야 함)
      ☐ 화면 오른쪽 위의 터미널 모양 아이콘(>_)을 누르면, 화면 아래에 검은 창이 열립니다. 처음 켤 땐 10~30초 걸립니다.
      ⚠️ 중간에 「Cloud Shell 승인」이 뜨면 [승인]을 누르세요. gcloud 명령을 처음 쓸 때 한 번 물어봅니다. [거부]를 누르면 그 명령이 그냥 실패하는데, 무엇 때문인지 화면에 잘 안 보입니다.

      🟢 CLI 설치 단계 (한 번만 하면 계속 유지됨)

      ☐ 아래 명령어를 통째로 복사해서 터미널에 붙여넣고 Enter 
      npm install -g @anthropic-ai/claude-code
      뭘 하는 명령어인가요? claude 명령어 자체를 이 터미널에 설치하는 것입니다. "added N packages" 같은 문구가 뜨면 성공.

      🟡 권한 부여 단계 (한 번만)

      ☐ 아래 명령어에서 maim-data-YOUR_PROJECT_ID 부분을 본인 버킷 이름으로 바꿔서 붙여넣기 (버킷 이름이 기억 안 나면 먼저 터미널에 gcloud storage buckets list 입력해서 gs://로 시작하는 이름 확인) 
      gcloud storage buckets add-iam-policy-binding gs://maim-data-YOUR_PROJECT_ID \
  --member="user:$(gcloud config get-value account)" --role="roles/storage.objectAdmin"
      뭘 하는 명령어인가요? 지금 로그인한 내 구글 계정이 이 버킷에 파일을 쓸 수 있게 허락하는 것입니다. "Updated IAM policy" 문구가 뜨면 성공.

      🟣 실제 로그인 단계

      ☐ 아래 두 줄을 순서대로 붙여넣기 
      mkdir -p /tmp/maim-home && HOME=/tmp/maim-home claude login
      앞쪽은 로그인 정보를 떨어뜨릴 임시 폴더를 만드는 것이고, HOME=/tmp/maim-home 뒤의 claude login 이 진짜 로그인입니다. HOME= 을 지우거나 앞에 export 를 붙이지 마세요. export 를 쓰면 그 뒤로 이 검은 창의 gcloud 명령들이 제 설정을 못 찾아 줄줄이 실패합니다 — 그런데 화면에는 그 이유가 잘 안 보입니다.
      ☐ 터미널에 뜨는 파란 링크를 클릭(또는 복사해서 새 탭에 붙여넣기)
      ☐ 열린 브라우저 창에서 본인 계정(고르신 AI 의 계정)으로 로그인 → 승인
      ☐ 터미널로 돌아와 Logged in as [이메일] 문구가 뜨는지 확인 → 뜨면 성공

      🔴 마무리 단계 (이거 빠뜨리면 서버엔 로그인이 반영 안 됩니다 — 꼭 하세요)

      ☐ 아래 명령어도 버킷 이름을 본인 것으로 바꿔서 붙여넣기 
      gcloud storage rsync -r /tmp/maim-home/.claude gs://maim-data-YOUR_PROJECT_ID/home/.claude
      뭘 하는 명령어인가요? 방금 만든 로그인 정보를 실제 서버(Cloud Run)가 읽는 위치로 옮기는 것입니다. 이걸 빼먹으면 터미널에서는 로그인됐지만 서버는 여전히 로그인 안 된 상태로 남습니다.
      제대로 갔는지 확인하시려면 gcloud storage ls gs://maim-data-YOUR_PROJECT_ID/home/.claude/ — 파일 이름들이 보이면 맞고, .claude/ 가 한 번 더 보이면 잘못 들어간 것입니다.

      ✅ 확인

      ☐ 이 페이지로 돌아와 위의 "연결 테스트" 버튼 클릭 → "✅ 연결 성공"이 뜨면 전체 완료
      ○ 2단계. Unsplash API 키 [매뉴얼 보기]

      무료 스톡 이미지 검색에 사용됩니다. unsplash.com/developers에서 무료로 가입 → New Application → Access Key를 복사해서 붙여넣으세요.

      1. unsplash.com/developers 접속
      2. 우측 상단 "Register as a developer" 클릭(구글 계정으로 바로 가입 가능, 무료)
      3. 가입/로그인 후 "Your apps" 페이지에서 "New Application" 클릭
      4. 이용약관 체크박스 2개 모두 체크 후 "Accept terms" 클릭
      5. 애플리케이션 이름(예: maim blog)을 간단히 입력 후 "Create application" 클릭
      6. 생성된 앱 페이지 상단의 "Access Key" 값을 복사
      7. 위 입력란에 붙여넣고 "저장" 클릭

      ※ 무료 요금제 기준 시간당 50회 검색까지 가능해 이 프로그램 사용량엔 충분합니다.
      💡 검색한 주제와 정확히 맞는 사진이 없어도 걱정 마세요 — 이 프로그램은 자동으로 점점 더 넓은 범용 키워드(예: lifestyle, nature landscape)로 재검색해서 이미지를 최소 3장은 항상 확보합니다.

      ○ 3단계. Pexels API 키 [매뉴얼 보기]

      Unsplash 검색 결과가 부족할 때 함께 사용되는 보조 이미지 검색 API입니다. pexels.com/api에서 무료로 가입 → API 키를 복사해서 붙여넣으세요.

      1. pexels.com/api 접속
      2. "Get Started" 클릭 → 이메일 또는 구글 계정으로 무료 가입
      3. 가입 즉시 API 키가 자동으로 발급되어 화면에 표시됩니다(별도 앱 생성 필요 없음)
      4. 표시된 API 키를 복사
      5. 위 입력란에 붙여넣고 "저장" 클릭

      ※ 무료 요금제로 시간당 200회 요청까지 가능합니다.

      ○ 4단계. Pixabay API 키 [매뉴얼 보기]

      Unsplash·Pexels와 함께 이미지 검색에 쓰이는 세 번째 무료 소스입니다. 소스가 하나 더 있으면 특정 주제에 맞는 사진을 못 찾을 확률이 줄어듭니다. pixabay.com/api/docs에서 무료로 가입 → API 키를 복사해서 붙여넣으세요.

      1. pixabay.com/api/docs 접속
      2. 우측 상단에서 회원가입(이메일 또는 구글 계정, 무료)
      3. 로그인 후 같은 페이지로 돌아오면 상단에 본인 계정용 API 키가 바로 표시됩니다(별도 앱 생성 필요 없음)
      4. 표시된 API 키를 복사
      5. 위 입력란에 붙여넣고 "저장" 클릭

      ※ 무료 요금제로 시간당 5,000회 요청까지 가능해 세 소스 중 한도가 가장 넉넉합니다.

        모든 화면 맨 위에 👤 누가 접속 중인지 · 🤖 글 쓰는 AI · 연결 상태 · 🖼️ 무료 이미지 키가
                늘 보입니다. 초록이면 준비 끝, 빨강이면 지금은 글이 나오지 않습니다.
        
              
        빨간 막대의 [AI 설정으로 가기]·[이미지 키 넣기]를 누르면
                고칠 자리로 바로 갑니다. 최근에 AI 가 바뀌었으면 «언제 무엇 → 무엇» 도 함께 보입니다.
        
              
        빨간 막대가 보이면 보내 주신 분께 알려 주세요. 체험 회원이 고칠 곳은 아닙니다.
        
            
        
          
        
          
        
            
        1
        
            
        
              
        블로그 관리에서 카테고리 설정
        
              
        기본 카테고리 3개(「부동산 이야기」 「생활 절세」 「일상 기록」)가 이미 준비돼 있습니다.
                이름·설명을 [수정]으로 내 블로그 주제에 맞게 바꾸시거나, 지우고 새로 만드셔도 됩니다.
                카테고리 하나가 초안 하나입니다.
        
              
        이번에 꼭 다루고 싶은 이슈가 있으면 [주제 키워드]를 한 번 채워 두세요. 다음 글에 최우선으로
                반영되고, 쓰고 나면 저절로 비워집니다.
        
              
        「하루 편수」 칸은 아침 자동 준비 때 그 카테고리에서 몇 편을 만들지 정합니다 (7번 참고).
        
            
        
          
        
          
        
            
        2
        
            
        
              
        내 블로그 방향 정하기
        
              
        왼쪽 [내 글 스타일]에서 블로그 유형(개인·기업)·주제 분야·말투(톤)·보강 문구·
                최소 글자수를 정합니다. 이 체험 키에만 저장되고, AI 설정은 따로 하실 필요가 없습니다.
                처음 들어오시면 이 화면이 먼저 열립니다.
        
              
        [관리자 설정 → 2) 블로그 주제 설정 · 3) 포스팅 방향 설정]에서 블로그 유형·
                주제 분야·톤 프리셋·보강 문구·최소 글자수를 정합니다. [예시 포스팅 보기]로 톤을 먼저 확인해 보세요.
        
            
        
          
        
          
        
            
        3
        
            
        
              
        [지금 생성] 클릭
        
              
        AI 가 카테고리 설명과 내 블로그 방향을 바탕으로 글을 쓰고, 어울리는 무료 사진 3장을 찾아 붙입니다.
                2~5분 걸리고, 끝나면 [포스팅]에 나타납니다.
        
              
        AI 연결이 끊겼거나 무료 이미지 키가 하나도 없으면, 기다리게 하지 않고 안내 창이 먼저 뜹니다.
        
              
        체험 키는 하루 3건까지 만들 수 있습니다.
        
            
        
          
        
          
        
            
        4
        
            
        
              
        포스팅에서 결과 확인 · 제목 고르기
        
              
        제목은 [검색 키워드] + [눌러 보고 싶게 만드는 말]로, 네이버 검색 결과에 다 보이는
                32~40자로 나옵니다.
                
        예) 노원구 소형 아파트 대출 조건 2026 바뀐 한도 3가지 총정리
        
              
        본 제목 아래에 후킹 제목 후보 3가지(조건·기준형 / 방법·절차형 / 후기·비교형)가 글자 수와 함께
                붙습니다. 마음에 드는 것을 [복사하기]로 가져가세요.
        
              
        제목을 누르면 본문이 펼쳐집니다. 품질 체크리스트(글자수·서식·키워드·주제 중복)를 보시고, 사진이 마음에
                안 들면 [이미지 재생성]으로 3장을 더 받을 수 있습니다.
        
            
        
          
        
          
        
            
        5
        
            
        
              
        네이버 블로그에 붙여넣기
        
              
        [복사하기]로 제목+본문+태그를, [이미지 복사]로 사진 자체를 담아 네이버 편집기에
                Ctrl+V 로 붙여넣으세요. 사진 아래 파란 상자의 대체텍스트도 네이버 편집기의 「대체텍스트」 칸에
                넣으면 이미지 검색에 도움이 됩니다.
        
              
        직접 겪은 이야기 한두 줄을 더하고 발행하세요. AI 는 겪은 것을 모릅니다 — 그 한두 줄이 검색에서
                이 글을 올려 줍니다.
        
            
        
          
        
          
        
            
        6
        
            
        
              
        발행 완료로 표시
        
              
        네이버에 올리신 뒤 [발행 완료로 표시]를 누르면 [발행 이력]에 남고,
                다음 글이 최근 제목 20개와 겹치지 않게 나옵니다. 이 프로그램은 네이버를 들여다볼 수 없어서
                눌러 주신 것으로 압니다.
        
            
        
          
        
          
        
            
        7
        
            
        
              
        관리자 설정 — AI 하나 + 무료 이미지 키 1개 이상
        
              
        1) AI 커넥트 연결에서 글 쓸 AI 를 하나 고릅니다 —
                Claude(Pro 이상 구독) · Gemini(구글 계정 무료 키) · Codex(ChatGPT Plus 이상 구독).
                AI 를 바꿀 때는 확인 창이 뜹니다. 바꾸면 이 서버의 모든 글(체험 회원 글 포함)이 새 AI 로 써지니,
                바꾼 뒤 꼭 [연결 테스트]를 눌러 «연결 성공» 을 확인하세요.
        
              
        무료 이미지 키(Unsplash · Pexels · Pixabay)는 1개 이상 있어야 글을 만들 수 있습니다.
                셋 다 넣어 두시면 하나가 한도에 걸려도 사진이 계속 나옵니다.

        매일 아침 자동으로 준비되게 하기
        
              
        [관리자 설정 → 4) 포스팅 예약 설정]에서 차례와 하루 몇 건을 정해 두시면,
                아침 6시에 준비돼 있습니다. 카테고리별 편수는 [블로그 관리]의 「하루 편수」
                칸에서 정합니다. 무료 이미지 키가 하나도 없으면 아침 준비도 건너뜁니다.
        
              
        예약 화면 맨 위에 ⏰ 자동 준비가 … 경고가 떠 있다면, 아직 자명종(Cloud
                Scheduler)을 한 번도 안 걸어 두신 것입니다. 설치 안내서의 6단계를 따라 한 번만 걸어 두시면 됩니다.
        
            
        
          
        
        
        

        
        
          
        왜 자동 발행이 아니라 반자동인가요?
        
          
        이전에 네이버 블로그 에디터를 자동으로 조작하는 방식을 시도했다가, 네이버가 이를
            자동화 도구로 탐지해 계정에 보호조치(비밀번호 강제 재설정)가 걸린 적이 있습니다. 그 이후로 이
            프로그램은 "AI가 글과 이미지를 준비 → 사람이 직접 복사해서 발행"하는 반자동 방식으로 설계를
            바꿨습니다. 네이버 비밀번호를 넣는 칸이 아예 없습니다. 복사 한 번이 계정을 지킵니다.
        
        
        

        
        
          
        자주 막히는 부분
        
          
        「AI 연결이 필요합니다」 창이 떠요 —
            맨 위 막대에서 지금 어느 AI 인지 확인하시고, 창의 [확인]으로 AI 설정에 가서
              [연결 테스트]를 누르세요. «로그인이 풀렸습니다» 가 나오면 설치 안내서 4단계 [나]의 ③·④
              (검은 창에서 다시 로그인 → 저장통에 올리기)를 하시면 됩니다. 서버를 다시 켤 필요는 없습니다.
            보내 주신 분께 «AI 연결이 끊겼다» 고 알려 주세요. 이때는 하루 한도가 줄지 않습니다.
        
          
        「무료 이미지 키가 필요합니다」 창이 떠요 —
            창의 [확인]을 누르면 이미지 키 칸으로 갑니다. Unsplash · Pexels · Pixabay 중
              하나 이상 키를 넣고 [저장]하세요. 셋 다 무료이고 가입하면 바로 나옵니다.
            보내 주신 분께 «이미지 키가 없다» 고 알려 주세요.
        
          
        오류 창이 떴어요 — 창의 [복사]를 눌러 내용을 그대로 전해 주시면
            바로 확인할 수 있습니다. 체험 회원에게 뜬 오류도
              [관리자 설정 → 🧯 최근 오류]에 누가·언제·무슨 오류였는지 남습니다.
        
          
        글은 나왔는데 사진이 없어요 — 무료 사진 사이트의 한도를 넘긴 것입니다. 시간이 지나면
            풀립니다. 급하면 글만 먼저 올리고 사진은 직접 넣으셔도 됩니다.
        
          
        아침에 아무것도 안 쌓여 있어요 — 예약 화면(관리자 설정 → 4)의
            맨 위를 보세요. ⏰ 자동 준비가 … 경고가 떠 있으면 자명종이 안 걸린 것입니다.
            하루 건수가 0 이거나, 무료 이미지 키가 하나도 없어도 아무것도 안 나옵니다.
        
          
        갑자기 로그아웃됐어요 / 접속 창이 계속 떠요 — 같은 2차 인증키를 다른 기기에서
            쓰시면 먼저 쓰던 기기가 끊깁니다. 메일에서 지금 기기(PC·노트북·휴대폰)에 맞는 2차키를 찾아
            넣으세요. 체험 기간이 끝났어도 접속 창이 뜹니다.
