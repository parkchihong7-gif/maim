# 집 PC 게임 캡처 프로그램 (agent)

게임 화면을 찍어 maim 서버로 보내고, 서버가 퀘스트별 공략 글 초안을 만든다.
**발행은 사람이 한다.** 이 프로그램은 **주인 자리 전용**이다.

> 지금은 **0단계(시험)** 만 들어 있다. 본 프로그램(`main.py` 등)은 1~4단계에서 추가한다.

## 1. 설치 (한 번만)
1. Python 3.11 이상을 설치한다(python.org, 설치할 때 "Add python.exe to PATH" 체크).
2. 명령 창에서 이 폴더로 가서:
   ```
   pip install -r requirements.txt
   ```
3. 저장 루트를 정한다. C 드라이브가 아닌 곳을 권장한다(예: `G:\maim-game`).
   ```
   setx MAIM_GAME_ROOT "G:\maim-game"
   ```
   (명령 창을 새로 열어야 적용된다.)

## 2. 0단계 시험
게임을 **공식 PC 클라이언트**로 켜고, **부계정**으로 들어간 상태에서 한다.

| 하는 일 | 명령 |
|---|---|
| 캡처 시험 (3장 + 영역 잘라내기) | `python tools/시험0.py --game dokkaebi` |
| 캡처 + ESC 1회 입력 시험 (도깨비의세계만) | `python tools/시험0.py --game dokkaebi --input-test` |
| 애니모 캡처 시험 (입력 없음) | `python tools/시험0.py --game aniimo` |
| 버튼·영역 좌표 비율 보기 | `python tools/시험0.py --game dokkaebi --coords` |
| 게임 켜기 시험 → 이어서 캡처 시험 | `python tools/시험0.py --game dokkaebi --launch` |
| 런처 [게임 시작] 버튼 좌표 재기 | `python tools/시험0.py --game dokkaebi --coords-launcher` |

**켜기 시험 전에**: `profiles/<게임>.yaml` 의 `실행.파일` 에 게임(또는 공식 런처) exe 경로를, 런처가 있으면
`실행.런처창제목` 을 적는다. 공식 런처의 **자동 로그인**을 켜 둔다. 이 프로그램은 아이디·비밀번호를 다루지 않는다.
도깨비의세계는 `실행.런처시작버튼` 좌표를 적으면 확인 후 한 번 눌러 준다. 애니모는 항상 사장님이 누른다.

- 결과는 `<저장 루트>\시험0\<게임>_<날짜시각>\` 에 사진과 `결과.json` 으로 남는다.
- `영역_퀘스트표시.png`·`영역_미니맵.png`·`영역_지역명.png` 가 엉뚱한 곳이면 `--coords` 로 비율을 재서
  `profiles/<게임>.yaml` 의 `영역`·`버튼` 값을 고친다.
- 결과 폴더의 `결과.json` 과 사진 몇 장을 Claude 세션에 보내 주면 다음 단계를 정한다.

### 결과 보는 법
- 캡처 ✔ + 입력 ✔ → 도깨비의세계 **감독 모드**로 진행
- 입력 ✘ → 그 게임은 **기록 모드**(사장님이 플레이, 프로그램은 캡처만)
- 캡처 ✘(검은 화면) → 게임 보안 프로그램이 막는 것일 수 있다. **우회하지 않는다.** Claude 세션에 알려 준다.

## 3. 지킬 것
- 결제·상점·거래소·경매장·채팅·문파/길드·우편·PvP 화면은 누르지 않는다.
- 클릭·키는 프로필 `버튼` 목록 안에서만. 기록 모드는 입력 0건.
- 게임 보안 프로그램을 피하거나 입력을 숨기는 기능은 넣지 않는다.
- 토큰 같은 비밀값은 파일에 적지 않고 환경변수로만 둔다.
