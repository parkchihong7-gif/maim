| # | 도톨이 | 요점 |

| 7 | 글 작성 준비 | 보관 키워드 선택 → 검색창 자동완성·«함께 많이 찾는» 으로 검색 방향 선택 → **실제 상위 5개 글 확보** → 형태소 → 사전 지식(출처) → **차별화 준비(필요한 내 자료)** → 승인. 원문 장기 보관 없음 |
| 8 | 글 작성 작업실 | 작성 모드 2(정보·해석 / 지식 기반 후기·경험) · 글 구성 «자동 추천 + 10종» · 분량 · **어조 강도 0~100%** · 내 경험·요청 입력 · 4구간 나눠 쓰기 · 탭(제목·목차 설계 / 초안·수정 / 출처·점검 / 스타일 적용) · 본문에 [자료 n] 출처 · 작성 관점 5(개인화·차별화·SEO·GEO·반복) |
| 9 | 최종 검수 | 초안 선택 → 검수 → 수정 → 재검수 → **최종본 따로 저장** → 서식 복사/TXT · 검수 항목: 스타일·작성 원칙·사실과 출처·경험 표현·참고 자료와 유사한 표현·과장/민감 표현 · 모바일 미리보기 · [이미지 생성 프롬프트 복사] |

글 구성 10종: ① 결론 먼저형 ② 궁금증 추적형 ③ 문제 해결형 ④ 비교·선택형 ⑤ 장면 출발형 ⑥ 오해 바로잡기형
⑦ 과정 따라가기형 ⑧ 핵심 발견 확장형 ⑨ 질문 연결형 ⑩ 관점 제시형 (+ 자동 추천)

NAVER API HUB 요금(2026-09): 검색 API 월 775,000건·하루 25,000건까지 0원, 검색어트렌드·쇼핑인사이트 월 50,000건까지 0원(일부 한시 무료).
