# 🕹️ 회사 PC 에서 «게임 시험 전 단계» 까지 확인하기

> 진짜 게임 없이, **가상 게임**으로 대시보드 ↔ 집 PC 프로그램 ↔ 서버 전체 흐름을 확인한다.
> 운영 서버·진짜 AI·진짜 게임은 건드리지 않는다. 데이터는 저장소 안 `data/game-test` 에만 쌓인다(지우면 처음부터).
> 마지막 갱신: 2026-10-21

## 0. 무엇을 확인하나
| 확인할 것 | 어디서 |
|---|---|
| 집 PC 연결 상태 막대(끊김 → 준비됨 → 켜는 중 → 자동 진행/직접 플레이) | 🕹️ 게임 플레이 → 메인 |
| [▶ 게임 실행] → 가상 게임이 켜지고 퀘스트를 인식, 사진이 쌓임 | 메인 «방금 남긴 사진»·«지금 퀘스트» |
| 감독 모드: 화이트리스트 버튼만 누름, 지도 자동 찍기, 막히면 직접 플레이 대기 | 메인 «직접 플레이 대기», 집 PC 창 로그 |
| 기록 모드(애니모): 입력 0건, 캡처만 | 집 PC 창 로그에 👆 가 없어야 함 |
| 미션 만들기 → 목표 다 채우면 자동 정지 | 미션 탭 |
| 게임 미션 목록 읽기(🔄) → 확인 필요 줄에 [📷 캡처 추가] → 사람 확인 | 미션 탭 |
| 앨범 순서 바꾸기·빼기 → 📚 참고 글 → 공략 글 만들기 | 앨범·공략 글 탭 → 📝 포스팅 |
| 카테고리 ⑧ 연결 게임 → [지금 생성] 이 무료 이미지 대신 내 캡처 3장 | 📁 블로그 관리 → 📝 포스팅 |
| 포스팅 카드 [🕹️ 내 게임 캡처에서 고르기] — 8장씩 쪽 넘기기 | 📝 포스팅 |
| 금지 화면(상점) → 즉시 정지 | `--금지` 로 켜서 메인 상태 막대 «확인 필요» |

글 내용은 **가짜 AI** 가 쓰는 고정 문장이다(모양만 확인). 진짜 글 품질은 운영 서버에서 본다.

## 1. 설치 (한 번만, 약 10분)
명령 프롬프트(cmd)를 **관리자 아님**으로 열고:
```
winget install OpenJS.NodeJS.LTS
winget install Python.Python.3.12
```
- winget 이 없으면 nodejs.org(LTS) · python.org 에서 받아 설치. Python 설치 첫 화면에서 **«Add python.exe to PATH» 체크**.
- 설치 후 **명령 프롬프트를 새로 연다**(PATH 적용). 확인: `node -v` (20 이상), `python --version` (3.11 이상)

저장소 폴더(`D:\클로드\블로그\maim`)에서:
```
git pull
npm install
cd agent
pip install -r requirements.txt
cd ..
```
- `npm install` 이 better-sqlite3·sharp 를 받는다(윈도용 미리 만든 파일이 있어 따로 빌드 도구는 필요 없다).
- 회사 보안 프로그램이 `pip`·`npm` 내려받기를 막으면 IT 에 «nodejs.org / pypi.org / registry.npmjs.org 허용» 을 요청한다.

## 2. 켜기 (매번)
저장소 폴더에서 **명령 하나**:
```
node tools/게임시험.mjs
```
- 서버(가짜 AI)와 집 PC 프로그램(가상 게임, 빠르게)이 한 창에서 같이 켜진다.
- 브라우저로 **http://127.0.0.1:8793** → 접속키 칸에 `owner-test-token-local`
- 왼쪽 메뉴 **🕹️ 게임 플레이**. (안 보이면 [📁 블로그 관리] 에서 이름에 «게임» 이 들어간 카테고리를 하나 만든다 — 운영과 같은 규칙: 주인 + 게임 블로그일 때만 메뉴가 보인다)
- 끄기: 그 창에서 `Ctrl+C`. 집 PC 프로그램을 **두 개 켜지 않는다**(같은 서버에 둘이 붙으면 명령을 서로 가져간다).

변형:
| 명령 | 하는 일 |
|---|---|
| `node tools/게임시험.mjs --금지` | 가상 게임 첫 퀘스트 중간에 «상점» 화면 → 즉시 정지 시험 |
| `node tools/게임시험.mjs --서버만` | 서버만 켜고, 집 PC 프로그램은 다른 창에서 직접(`cd agent` → `python main.py --가상 --빠르게`) |

## 3. 순서대로 눌러 보기 (약 5분)
1. 메인 상태 막대가 **«준비됨 — 집 PC 대기 중»(초록)** 인지 본다.
2. 게임 «도깨비의세계 · 감독 모드», 미션 «없이» → **[▶ 게임 실행]**. 3~5초 뒤 «켜는 중 → 자동 진행 중».
   - 집 PC 창: `📜 퀘스트` → `📸` → `👆 [가상] 임무수락` → `👆 지도열기` → `🗺️ 지도 찍음` …
   - 2번째 퀘스트 «잃어버린 장부» 는 일부러 멈춘다 → 15초 뒤 `🙋 막힘` → 메인 «직접 플레이 대기» 에 카드.
   - 3번째 퀘스트까지 끝나면 «모든 퀘스트를 마침» 으로 스스로 멈춘다.
3. 메인 퀘스트 표 → [앨범] → ↑↓·빼기 → 아래 📚 참고 글 → [🔎 찾아 넣기] → 후보 체크 → [체크한 것 넣기] → **[참고해서 공략 글 만들기]** → 📝 포스팅에 «🕹️ 게임 공략» 카드.
4. 미션 탭 → [🔄 게임에서 다시 읽기] → 목록 6줄. «붉은 ■■의 …» 줄(확인 필요) → [📷 캡처 추가] → [🖼️ 최근 사진에서 고르기] → 사진 하나 → 값 고치고 [✔ 확인].
5. 미션 탭 → [이 순서로 미션 만들기] 또는 ＋ 새 미션(목표·필요한 사진 체크) → [▶ 실행] → 목표를 채우면 «미션 목표를 다 채웠습니다» 로 자동 정지.
6. 게임을 «애니모 · 기록 모드» 로 실행 → 집 PC 창에 👆 가 **한 번도 없어야** 한다(입력 0건).
7. [📁 블로그 관리] → 카테고리 수정 → **⑧ 연결 게임 = 도깨비의세계** → [지금 생성] → 포스팅 카드에 캡처 3장, [🕹️ 내 게임 캡처에서 고르기] 로 8장씩 넘기며 골라 넣기.
8. 휴대폰 폭: 브라우저 창을 좁히거나 F12 → 기기 모드(375px)에서 메인이 가로로 넘치지 않는지.

## 4. 이 단계에서 «안 되는 것» (집 PC 에서 할 일)
- 진짜 게임 창 찾기·캡처(mss·pywin32), 진짜 키·클릭(pydirectinput), F9·F10·F12 전역 단축키 — 윈도 + 게임이 있어야 한다.
  (회사 PC 에서도 단축키 라이브러리는 설치되지만 가상 게임에는 쓸 일이 거의 없다.)
- 버튼 좌표·영역 비율 채우기 → `agent/tools/시험0.py --coords` (0단계)
- 진짜 AI 의 판단 정확도 → 운영 서버 배포 후 집 PC 에서.

## 5. 탈이 나면

|---|---|
| `npm install` 중 better-sqlite3 빌드 오류 | Node 를 LTS(20 또는 22)로 다시 설치. 23 이상의 홀수 판은 미리 만든 파일이 없을 수 있다 |
| `python` 을 못 찾음 | 새 명령 프롬프트에서 `py -3 --version`. 실행기는 `py -3` 도 찾는다 |
| 상태 막대가 계속 «연결 끊김» | 실행기 창에 집 PC 프로그램 줄(🕹️ 집 PC 게임 프로그램 …)이 떴는지. 없으면 `--서버만` 으로 켜고 다른 창에서 직접 |
| 한글이 □ 로 보이는 가상 게임 화면 | 맑은 고딕이 없을 때뿐. 윈도에는 기본으로 있다 |
| 처음부터 다시 | 끄고 `data\game-test` 폴더를 지운 뒤 다시 켠다 |
