# 🕹️ 게임 스샷 — 설계 (2026-10-21 개편, 현재 기준)

> 이전 «게임 플레이»(감독·기록 모드, 미션, 퀘스트 판단, 자동 진행)는 **모두 걷어 냈다.** 세팅이 어렵고 실제로 잘 안 돌았다.
> `GAME_PLAN.md` 는 옛 계획 기록으로만 남긴다. 미리보기: https://claude.ai/artifact/GKAgbvgsRwFMC5jBwb4KxK

## 1. 흐름
1. **게임 등록** — 대시보드 [🕹️ 게임 스샷 → 게임 목록] 에 «게임 이름» + «창 제목 글자». 도깨비의세계(`도깨비의세계 -`)·애니모(`Aniimo`)는 처음부터 있다.
2. **집 PC 프로그램 켜기** — 바탕화면 «maim 게임 켜기»(관리자 권한, `agent/켜기.cmd`). 대시보드에서 따로 실행 버튼 없음.
3. **플레이 중 단축키(기본 F9)** — 맨 앞 창을 찍는다 → 집 PC 에 원본 저장 → 서버에 올림. 서버가 창 제목으로 게임을 찾고, 목록에 없으면 «기타».
   단축키는 게임에 넘기지 않는다(도깨비의세계는 F9 가 우편함).
4. **글** — 카테고리 ⑧ «연결 게임» 을 고른 카테고리 글은 무료 이미지를 찾지 않고 **그 게임의 아직 안 쓴 최근 스샷 3장**을 붙인다(AI 고르기 없음).
   📝 포스팅 카드: 사진 [이미지 복사] → 네이버 에디터 Ctrl+V · [+ 스샷 더 넣기] · [🔄 스샷 바꾸기](8장씩 고르기 창).

## 2. 정한 것 (기본값)
| 항목 | 값 |
|---|---|
| 단축키 | F9 (설정에서 F6~F11·Print Screen) — 집 PC 가 30초마다 받아 감 |
| 글에 자동 붙이는 장수 | 3장, 그 게임에서 어떤 글에도 안 쓴 최근 것부터 |
| 목록에 없는 창 | «기타» 에 저장. 앨범에서 [이 게임으로 등록] → 같은 창 제목 스샷이 다 옮겨 감 |
| 예전 DB 표 | 지우지 않음(game_sessions·game_quests·game_missions·game_play_log·game_quest_list 는 안 씀) |
| 보관 | 집 PC 원본 30일 · 안 쓴 스샷 60일 · 글에 쓴 스샷은 발행 30일 뒤 (설정에서 바꿈) |
| 접속 | 관리자 접속(마스터 토큰)만. 판매용·체험 키는 메뉴·API 모두 404. 저장통(GAME_SHOT_BUCKET) 없으면 기능 꺼짐 |

## 3. 코드
```
src/game/프로필.ts            게임 {id, 이름, 창제목} · 기본 게임 2개 · 창으로게임(긴 글자부터)
src/game/사진저장.ts          저장통(GCS 또는 local:) 넣기·읽기·지우기·서명 주소
src/game/캡처고르기.ts        pickGameShots(안 쓴 최근 N장) · 캡처를글에(글 폴더로 복사)
src/db/repositories/gamePlay.ts  설정(단축키·보관일) · 토큰 · 게임 목록 · 스샷 · 글에 쓴 스샷 · 정리 대상
src/web/routes/game.ts        API (아래)
src/web/public/game.js        스샷·게임 목록·설정 탭, 포스팅 카드 고르기 창, 카테고리 ⑧
src/scheduler/게임사진치우기.ts  매일 새벽 4시 정리
agent/main.py                 집 PC: 단축키 → 찍기 → 원본 저장 → 올리기 (못 올리면 «보낼것» 에 두고 다시)
agent/창.py · 저장.py · 올리기.py · 설정.py · tools/게임찾기.py(창 제목 보기)
```
`game_shots.window_title` 칸이 새로 붙는다(db/index.ts 칸붙이기).

### API
- 집 PC(`x-game-agent-token`): `POST /api/game/agent/heartbeat` → `{settings:{단축키,원본보관일}, games}` · `POST /api/game/agent/shot {image, window_title, taken_at}`
- 화면(관리자): `GET /api/game/status` · `GET/POST /api/game/games` · `PUT /api/game/games/:id` · `POST /api/game/etc/register`
  · `GET /api/game/shots?game&day=today|yesterday|7d|all&unused&page&size` · `GET /api/game/shots/:id/img[?raw=1]` · `PUT /api/game/shots/:id`
  · `POST /api/game/shots/delete {ids}` · `POST /api/game/upload` · `GET/PUT /api/game/settings` · `GET /api/game/agent-token` · `POST /api/game/agent-token/new`
- 포스팅 카드: `GET/POST /api/posts/:id/game-shots` · `DELETE /api/posts/:id/game-shots/:shotId` · `POST /api/posts/:id/game-shots/auto`

## 4. 시험
- 서버: `npx tsx tests/test-게임플레이.ts` (가짜 AI, 로컬 저장통)
- 집 PC: `cd agent && python -m pytest tests -q`
- 실제 게임: `python agent\main.py --시험찍기 3` (3초 뒤 맨 앞 창 한 장) · `--연결시험`
