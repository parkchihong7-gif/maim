시안 6 — 사진 저장통이나 집 PC 연결이 아직 없을 때. 게임 기능 전체를 막고 할 일만 보여 준다.

게임 플레이

시작하려면 아래 두 가지를 먼저 해 주세요.

⛔ 사진 저장통이 연결되지 않았습니다. Cloud Shell에서 저장통을 만들고 GAME_SHOT_BUCKET을 넣어 다시 배포해 주세요. 순서 보기 →
🔌 집 PC가 아직 연결된 적이 없습니다. 집 PC에서 python main.py를 켜 두면 여기 «연결됨»이 뜹니다. 설치 안내 →

처음 세팅 순서

  1. Cloud Shell — 사진 저장통 만들기 · 권한 주기 · 배포 아직
  2. 집 PC — Python 설치, pip install -r requirements.txt 확인 불가
  3. 집 PC — 환경변수 3개 (서버 주소 · 집 PC 토큰 · 저장 위치) 확인 불가
  4. 집 PC — 0단계 시험 (켜기 · 캡처 · 입력) 확인 불가
  5. 집 PC — python main.py 켜 두기 → 첫 연결 아직
