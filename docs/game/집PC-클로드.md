# 🏠 집 PC — 클로드가 대신 하는 게임 연결 순서

> 사장님은 **A** 만 하시면 됩니다. **B** 는 집 PC 의 Claude Code 가 이 파일을 읽고 직접 합니다.
> 마지막 갱신: 2026-10-21

---

## A. 사장님이 하실 것 (5군데)

### ① Cloud Shell — 새 코드 배포 (한 번)
```
cd ~/maim && git fetch origin claude/game-play-ontn8y && git switch claude/game-play-ontn8y && git pull
bash deploy/게임배포.sh
```

### ② 대시보드 — 토큰 복사
🕹️ 게임 플레이 → **설정** 탭 → 맨 위 **🔑 집 PC 연결** → [토큰 만들기](이미 있으면 생략) → **[📋 복사]**

### ③ 집 PC — Claude Code 열기
1. Claude 앱 → Code → 작업 폴더 = **G 드라이브의 maim 저장소 폴더**
2. 입력창 아래 모드를 **Shift+Tab** 으로 «auto»(자동)로 바꾼다 — 클로드가 명령마다 묻지 않고 진행
3. 아래를 그대로 붙여 넣는다:
```
git fetch origin claude/game-play-ontn8y 하고 그 브랜치로 바꾼 뒤(git switch, git pull),
docs/game/집PC-클로드.md 를 읽고 «B. 클로드가 할 일» 을 순서대로 진행해 줘.
내가 직접 해야 하는 것(토큰 붙여넣기, 게임 켜기)은 그때그때 짧게 알려 줘.
```

### ④ 클로드가 부르면 (두 번)
- **파란 PowerShell 창이 뜨면**: 질문 3개 — 서버 주소 `Enter` → 토큰 **마우스 오른쪽 클릭(붙여넣기)** 후 `Enter` → 저장 폴더 `Enter`
- **«게임을 켜 주세요» 라고 하면**: 그 게임을 공식 클라이언트로 켜고 **부계정**으로 캐릭터 화면까지 들어간 뒤 «켰어» 라고 답

### ⑤ 대시보드 — 첫 실행 (클로드가 «준비 끝» 이라고 한 뒤)
1. 메인 상태 막대가 초록 **«준비됨»** 인지 본다
2. 게임 **애니모 · 기록 모드** → [▶ 게임 실행] → 직접 플레이 → «방금 남긴 사진» 이 쌓이는지
3. 끝내기: [⏹ 즉시 정지] (또는 집 PC 에서 F12)
4. 도깨비의세계(감독 모드)는 클로드가 «버튼 좌표를 넣었습니다» 라고 한 뒤에

## B. 클로드가 할 일 (집 PC Claude Code 용)

> 지킬 것: 게임에 보내는 입력은 **아래 1-4 의 ESC 1회뿐**이다(도깨비의세계만, 사장님이 보는 앞에서).
> 아이디·비밀번호는 다루지 않는다. 토큰 값은 채팅·파일·저장소에 쓰지 않는다(사장님이 PowerShell 창에 직접 붙여 넣는다).
> 보안 프로그램이 캡처·입력을 막으면 우회하지 않고 그대로 보고한다. 설명은 한국어로 짧게.

### B-0. 저장소
- `git fetch origin claude/game-play-ontn8y` → `git switch claude/game-play-ontn8y` → `git pull`
- Python 3.11 이상인지: `python --version` (없으면 `py -3 --version`). 아니면 사장님께 python.org 설치를 부탁하고 멈춘다.

### B-1. 준비 스크립트 (사장님이 토큰 입력)
1. 새 창으로 띄운다(클로드 창에서는 토큰 입력을 받을 수 없다):
   `start powershell -NoExit -ExecutionPolicy Bypass -File agent\집PC-준비.ps1`
2. 사장님께: «파란 창에서 Enter → 토큰 붙여넣기 Enter → Enter 해 주세요. 끝나면 '됐어' 라고 해 주세요.»
3. 확인: `python agent\main.py --연결시험` → `✅ 연결됨` 이면 다음. ❌ 면 문구로 원인을 찾는다
   (401 = 토큰 다름 → ② 다시 복사 후 1번 반복 / 404·연결 실패 = 서버 주소·배포 확인 / 503 = 대시보드에서 토큰 미생성).

### B-2. 애니모 (기록 모드) — 캡처 시험·프로필 채우기
1. 사장님께 «애니모를 켜고 캐릭터가 움직일 수 있는 화면까지 들어가 주세요. 퀘스트 표시와 미니맵이 보이게요.»
2. `python agent\tools\게임찾기.py Aniimo 애니모` → 창제목·실행 파일 경로·창 크기 확인
3. `agent\profiles\aniimo.yaml` 의 `창제목` 을 찾은 제목(부분 일치로 충분한 짧은 말)으로 고친다
4. `python agent\tools\시험0.py --game aniimo` (입력 없음, 캡처만) → 결과 폴더(`<MAIM_GAME_ROOT>\시험0\aniimo_…` 또는 `agent\시험결과\시험0\…`)의
   `결과.json` 과 `shot1.png` 를 Read 로 본다.
   - 검은 화면이면: 창 모드/전체화면 바꿔 다시. 그래도 검으면 «보안 프로그램이 캡처를 막는 것 같다» 보고하고 멈춘다(우회 금지).
5. `shot1.png` 를 보고 화면 비율(0~1)로 영역을 정한다: **퀘스트표시**(진행 중 퀘스트 글자 상자) · **미니맵** · **지역명**(지역 이름 글자) · **목록**(퀘스트 목록 창을 열었을 때 목록 부분 — 모르면 그대로)
   - `aniimo.yaml` 의 `영역` 을 고치고 4번을 다시 돌려 `영역_*.png` 가 그 부분만 잘렸는지 눈으로 확인 → 맞을 때까지 반복
6. 서버에 올린다:
   `python agent\tools\프로필올리기.py --game aniimo --창제목 "<제목>" --파일 "<exe 경로>" --영역 퀘스트표시=x,y,w,h --영역 미니맵=x,y,w,h --영역 지역명=x,y,w,h`
   - 런처가 따로 있으면 `--파일` 은 **런처 exe**, `--런처창제목 "<런처 창 제목>"` 도 같이.

### B-3. 도깨비의세계 (감독 모드) — 캡처 + ESC 1회 + 버튼 좌표
1. 사장님께 «도깨비의세계를 **부계정**으로 켜고 필드 화면까지 들어가 주세요»
2. B-2 의 2~6 을 `dokkaebi` 로 똑같이 (`게임찾기.py 도깨비`, `시험0.py --game dokkaebi`)
3. 입력 시험(딱 한 번, 사장님 동의 후): «게임에서 가방이나 지도 창을 하나 열어 두세요. ESC 를 1번 보내 닫히는지 봅니다» →
   `python agent\tools\시험0.py --game dokkaebi --input-test --동의함`
   → `입력_전.png`·`입력_후.png` 를 보고 창이 닫혔으면 **입력 ✔**. 안 닫혔으면 «게임이 입력을 막음 → 기록 모드로 쓰자» 고 보고(우회 금지).
4. 입력 ✔ 이면 `shot1.png` 에서 버튼 위치를 찾아 비율로 적는다: **자동진행 · 보상받기 · 임무수락** (키로 되는 것: 임무창열기 J · 지도열기 M · 창닫기 ESC 는 게임 설정 화면/화면 표시로 확인)
   - 버튼은 서버에서 **관리자만** 바꿀 수 있다. 사장님께 표로 보여 드리고 «대시보드 [설정 → 게임 프로필 → 버튼] 에 이 숫자를 넣고 [프로필 저장]» 을 부탁한다.
   - `agent\profiles\dokkaebi.yaml` 의 `버튼` 에도 같은 값을 적어 둔다(기록용).

### B-4. 켜 두기·기록
1. `agent\켜기.cmd` 를 바탕화면 바로가기로 만들고 실행해 둔다: `start "" "%CD%\agent\켜기.cmd"` (창이 하나 떠 있어야 한다. 두 개 띄우지 않는다)
2. 사장님께 «대시보드 메인 상태 막대가 초록 '준비됨' 이면 애니모로 [▶ 게임 실행] 해 보세요» (A-⑤)
3. `docs/game/인수인계.md` 7번 표(부계정·공식 클라이언트·원본 경로·0단계 결과·exe 경로)와 작업 기록을 채우고,
   바꾼 `agent/profiles/*.yaml` 과 함께 커밋·푸시(한국어 커밋, 브랜치 `claude/game-play-ontn8y`). 시험 사진·토큰은 올리지 않는다(`.gitignore`).
